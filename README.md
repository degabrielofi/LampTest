## Sobre o Projeto

Site interativo que simula o acionamento de uma lâmpada — clique para acender ou apagar. O projeto explora os fundamentos de **manipulação do DOM** com JavaScript, alternando estados visuais e classes CSS de forma dinâmica.

Apesar de sua simplicidade, o projeto representa um marco no aprendizado de interatividade no front-end: entender como JavaScript se comunica com o HTML/CSS para reagir a eventos do usuário.

> Projeto desenvolvido como parte da jornada de aprendizado em desenvolvimento front-end.

## Funcionalidades

- Alternar entre lâmpada acesa e apagada com um clique
- Mudança visual imediata via troca de classes CSS
- Interface simples e responsiva

## Como Instalar e Rodar

```bash
# Clonar o repositório
git clone https://github.com/degabrielofi/LampTest

# Entrar na pasta
cd LampTest

# Abrir no navegador
start index.html
```
